---
breed: munchkin-bernedoodle
intro: A Munchkin Bernedoodle comes from a Bernese and Poodle line bred small. Munchkin is a breeder's size name with no registry behind it, so each puppy's size and coat follow its own parents and generation.
---
Size varies. | Each breeder sets their own Munchkin size, so ask what each parent weighs.
Coat varies. | The Bernese side sheds heavily and the Poodle side barely sheds, so puppies can differ.
Family dog. | On AKC's scale the Bernese and the Poodle both rate 5 of 5 with young children.
Know the line. | Ask which Poodle size is in the line and which health screenings each parent has had.
