# Health test lists and where each one comes from

Each breed's list is its OFA CHIC program, loaded from ofa.org on October 21, 2026. The tests CHIC requires are listed first in the portal, then the tests the program lists as optional or elective. A breeder can tick any of them and write anything else in the Other box.

Where one program words a test differently from another, such as an eye exam at 12 months against one at 24 months, the portal shows one plain name for it, so a cross lists each test once. The exact wording from each OFA page is in the tables below.

## What to check

- Victorian Bulldog has no published list. OFA has no program for it, and its nearest entry, the Olde Victorian Bulldogge, is not yet part of CHIC. The portal offers the common screenings for it and says there is no published list for the breed.
- OFA publishes no general list. The common screenings are the six OFA tests most of these programs are built from: hips, elbows, eyes, heart, patellas and thyroid.
- Two items on the CHIC pages are not health tests, so they are left off the pick list. They are the Doberman working aptitude evaluation and the Yorkshire Terrier DNA banks.
- Crosses take the tests of both parent breeds. A cross bred from a Toy or Miniature Poodle takes the Miniature Poodle list, because it holds every Toy Poodle test and hips as well. The Mini Aussiedoodle takes both the Miniature American Shepherd and the Australian Shepherd lists, because breeders use either.
- Bernese Mountain Dog, Papillon and Pomeranian each require one test from an elective group. The portal lists the group as optional tests rather than enforcing the choice.
- A Bernese club page lists OVC hip and elbow evaluations, which OFA's current page does not, so they are not on the list.

### Australian Shepherd

The portal offers: Hips (x-ray evaluation) (required), Elbows (OFA) (required), Eyes (exam by a board-certified ophthalmologist) (required), Thyroid (autoimmune thyroiditis), Collie eye anomaly (DNA), MDR1 drug sensitivity (DNA).

Source: [OFA CHIC program, Australian Shepherd](https://ofa.org/chic-programs/browse-by-breed/?breed=AS), which says "recommends the following basic health screening tests for all breeding stock".
