# Wix parent photos, 2026-11-13

Decisions are recorded here as they are made.

- A litter where two puppies name different moms (or dads) is left out whole, for both roles, because a
  conflict there suggests the imported litter holds two real litters and any link could be wrong.
- Parent photos are copied to the parents/ key layout rather than pointing photo_key at the puppy's
  uploads/ key, because the cover-photo case keeps the puppy row, and an editor deleting that puppy photo
  would delete the parent's photo with it. The old puppy objects stay in R2 (not deleted).
